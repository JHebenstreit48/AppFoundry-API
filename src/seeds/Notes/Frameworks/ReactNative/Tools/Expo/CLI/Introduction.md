# Introduction to Expo CLI

<hr class="dividerSection" />

## What Is Expo CLI?

<hr class="dividerSection" />

<span class="emphasis">Expo CLI</span> is a free, open-source toolchain built on top of React Native that
provides a streamlined and managed workflow for building cross-platform apps.

It removes the complexity of manual native setup and lets developers focus purely on JavaScript and UI logic.

<hr class="dividerSection" />

## Why Use Expo CLI?

<hr class="dividerSection" />

Using <span class="emphasis">Expo CLI</span> makes React Native development faster and simpler — perfect for
teams or individuals who want to avoid manual Android and iOS configuration.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>No Xcode or Android Studio required for basic builds.</li>
    <li>Access to prebuilt device APIs via the Expo SDK.</li>
    <li>Fast refresh, easy debugging, and over-the-air (OTA) updates.</li>
    <li>Seamless integration with the <span class="emphasis">Expo Go</span> app for testing.</li>
  </ul>
</div>

<hr class="dividerSection" />

## Summary

<hr class="dividerSection" />

Expo CLI offers a managed approach that accelerates development while maintaining flexibility to switch to a
bare React Native workflow later.
